--------------------------------------------------
DESCRIPCION GENERAL
--------------------------------------------------
El programa trabaja con un grafo no dirigido representado mediante una matriz
de adyacencia de tamaño N x N.

En la matriz:
- 1 indica que existe una arista entre dos nodos.
- 0 indica que no existe arista.

El programa realiza lo siguiente:
1) Crea un grafo de ejemplo.
2) Imprime la matriz de adyacencia.
3) Obtiene las aristas únicas del grafo.
4) Busca todos los apareamientos no vacíos.
5) Muestra el tamaño del apareamiento máximo.
6) Muestra cuales son los apareamientos máximos.

Nota:

- Quisimos incluir lo de los apareamientos máximos, al ser esto un tema importante en el apareamiento de grafos.
Además visualmente, enriquece el entendimiento.

- La versión OpenACC mantiene el objetivo original de encontrar los apareamientos del grafo.
Sin embargo, para evitar sobrecarga de salida y facilitar la comparación con las versiones secuencial, OpenMP y MPI,
la impresión detallada de todos los apareamientos fue sustituida por un resumen global y la visualización de los
apareamientos máximos encontrados. El cálculo completo de los apareamientos sigue realizándose internamente.

- En esta versión se utiliza OpenACC para ejecutar en GPU la comprobación de los subconjuntos de aristas. A diferencia
de las versiones secuencial, OpenMP y MPI, aquí no se usa directamente el backtracking recursivo, porque la recursión no
es la forma más adecuada de paralelizar en GPU con OpenACC. En su lugar, se enumeran en paralelo todos los subconjuntos
posibles de aristas mediante máscaras de bits y se comprueba cuáles son apareamientos válidos.

INSTALACIÓN Y CONFIGURACIÓN DE OPENACC EN LINUX MINT (CASA)
--------------------------------------------------

Este documento resume todos los pasos realizados para conseguir un entorno funcional de OpenACC con GPU NVIDIA en un ordenador personal con Linux Mint.

------------------------
1. PREPARACIÓN DEL SISTEMA
------------------------

Se partía de un sistema Linux Mint instalado en un equipo con particiones múltiples (Windows + Linux + disco de datos).

Se verificó el hardware disponible:

    lsblk -f
    df -h

Se identificó:
- SSD principal con Linux Mint
- Disco secundario “Almacenamiento” (NTFS) para datos
- GPU NVIDIA GeForce GTX 1650

------------------------
2. BACKUP Y RESTAURACIÓN DE DATOS
------------------------

Se realizó copia de seguridad de datos personales usando rsync hacia un disco externo:

    rsync -avh --progress /home/lierni /media/.../backup

Problemas encontrados:
- El USB se llenó completamente (No space left on device)
- Se interrumpió la copia (Ctrl+C)
- Se tuvo que reanudar y corregir el proceso

Posteriormente se restauraron los datos desde el disco “Almacenamiento”:

    rsync -avh --progress /media/lierni/Almacenamiento/backup-lierni/ /home/lierni/

Resultado:
- Backup completo restaurado (~73 GB)

------------------------
3. INSTALACIÓN DE DRIVERS NVIDIA
------------------------

Se instaló el driver recomendado para la GPU:

    sudo ubuntu-drivers devices
    sudo apt install nvidia-driver-595

Verificación:

    nvidia-smi

Resultado:
- GPU detectada correctamente
- Driver NVIDIA 595 funcionando
- CUDA compatible reportado

------------------------
4. INSTALACIÓN DE CUDA
------------------------

Se añadió el repositorio oficial de CUDA:

    wget https://developer.download.nvidia.com/compute/cuda/repos/ubuntu2404/x86_64/cuda-keyring_1.1-1_all.deb
    sudo dpkg -i cuda-keyring_1.1-1_all.deb
    sudo apt update
    sudo apt install cuda-toolkit-13-2

Se configuró el PATH:

    export PATH=/usr/local/cuda/bin:$PATH
    export LD_LIBRARY_PATH=/usr/local/cuda/lib64:$LD_LIBRARY_PATH

Verificación:

    nvcc --version

Resultado:
- CUDA 13.2 instalado correctamente

------------------------
5. INSTALACIÓN DE NVIDIA HPC SDK (OPENACC)
------------------------

Se descargó el HPC SDK desde NVIDIA:

    wget https://developer.download.nvidia.com/hpc-sdk/...
    tar -xvf nvhpc_*.tar.gz
    sudo ./install

Instalación en:

    /opt/nvidia/hpc_sdk

Se configuró el entorno:

    export PATH=/opt/nvidia/hpc_sdk/Linux_x86_64/26.3/compilers/bin:$PATH

Verificación:

    nvc --version

Resultado:
- NVIDIA HPC SDK 26.3 instalado correctamente
- Compilador OpenACC funcional

------------------------
6. PROBLEMA CON GCC OPENACC
------------------------

Se intentó compilar con GCC:

    gcc -fopenacc -foffload=nvptx-none ...

Error:
- Falta soporte "nvptx-none"
- Falta mkoffload
- GCC no configurado para GPU OpenACC

Conclusión:
- GCC OpenACC no funcional en este sistema
- Se descarta su uso

------------------------
7. SOLUCIÓN FINAL (FUNCIONAL)
------------------------

Se adopta NVIDIA HPC SDK como herramienta principal:

Compilación:

    nvc -acc programa.c -o programa

Ejecución:

    ./programa

Verificación de GPU:

    nvidia-smi

------------------------
8. RESULTADO FINAL
------------------------

- Linux Mint funcionando correctamente
- GPU NVIDIA GTX 1650 detectada
- CUDA 13.2 instalado
- NVIDIA HPC SDK instalado
- OpenACC funcionando correctamente en GPU
- Compilación con nvc operativa

--------------------------------------------------
NOTAS SOBRE LA IMPLEMENTACION
--------------------------------------------------
- Se ha utilizado OpenACC para paralelizar parte del algoritmo en GPU.
- La paralelización se realiza con #pragma acc parallel loop.
- Se utiliza #pragma acc data copyin(...) para copiar a la GPU los arreglos con los extremos de las aristas.
- Se utilizan reducciones para acumular correctamente los resultados:
    - reduction(+:total) para contar apareamientos.
    - reduction(max:maximo) para obtener el tamaño máximo.
    - reduction(+:maximos) para contar los apareamientos máximos.
- Cada subconjunto de aristas se representa con una máscara de bits.
- Cada iteración del bucle paralelo comprueba si una máscara representa un apareamiento válido.
- Para comprobar si un subconjunto es válido, se usa una variable entera como máscara de vértices usados.
- La impresión de resultados se mantiene secuencial para evitar sobrecarga y mantener una salida ordenada.
- El grafo se ha definido como no dirigido, por lo que la matriz es simétrica.
- Para evitar duplicados, las aristas se recorren solo por encima de la diagonal principal (j = i + 1).
- Se usa una semilla fija, srand(1), para facilitar la comparación con las versiones secuencial, OpenMP y MPI.
